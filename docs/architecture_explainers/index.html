run_static_scene_graph.py

How the scene graph pipeline works

A walkthrough video goes in; a 3D map of named objects and how they rest on each other comes out. Each stage below has its own page with an interactive demo, the real parameters, and where it lives in the code. Click a stage to open it.

Capture
1–3 Frames, depth and camera pose
Resize each frame to 640 px, predict metric depth, track the camera pose, back-project pixels to 3D. Depth Anything V3 metric · DROID-SLAM
or dataset depth / poses
↓ metric depth (m) + intrinsics K + camera-to-world poses
Map
4a · 4 Gravity alignment and voxel map
Find the floor plane and rotate the world so z is up; every depth pixel becomes a 1 cm coloured voxel. RANSAC planes · worker processes
↓ z-up poses, voxel index for every pixel
Streaming · detection, embedding and fusion run as parallel threads
5 · 5a Detect, segment and track
Prompt-free YOLOE finds every object mask; BoT-SORT gives each a persistent track id; optional checks drop group boxes and wall pieces. YOLOE-26-seg-pf + BoT-SORT
↓ boxes · masks · track ids
5b Crop and embed
A padded box crop of every detection becomes a 1024-d CLIP embedding — what "looks alike" means downstream. NOVIC image embedder
CLIP DFN5B ViT-H-14
↓ one embedding per detection, mask → voxels
6 Track accumulation and commit
Detections of one track pile up; when the track ends it merges into the best-matching map object (0.3·overlap + 0.7·cosine ≥ 0.55) or becomes a new one. NOVIC decoder names the object at track end
3D instances
6 · 6b Final fusion and clean-up
At the end of the video: re-match, DBSCAN, overlap merge, voxel ownership; then drop floor slabs and merge fragments. DoVSG code, adapted
↓ fused 3D instances
7 Instance naming
The track-end NOVIC name, pooled over synonyms, mapped to an everyday noun; low-confidence names become "unknown". NOVIC decoder · label mapper
Scene graph
9 Spatial relations
Footprint overlap and heights decide on / inside / belongs / next to; the result is a floor-rooted tree. DoVSG rules + contact checks
Query · separate scripts
→ Task planning and scene update
Ground a spoken command to a node and a goal position; update the saved graph from a new video of the same room. Gemini 2.5 Flash + NOVIC text similarity
