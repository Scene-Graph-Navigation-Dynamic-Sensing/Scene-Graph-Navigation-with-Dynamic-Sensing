Final fusion and clean-up

When the video ends, the map holds one object per committed group of tracks — but some real objects are still split in two, some voxels are claimed twice, and big flat pieces of floor have become "objects". A fixed sequence of passes tidies this up before anything is named.

Step through the passes

A top-down toy map. Each pass changes it the way the real pass would.

Try it: would clean-up drop this as floor?

drop_structural_instances: the graph already has a floor root, so a large, thin object lying at floor height is a piece of floor, not furniture. The docstring names floor, rug and parquet: a flat rug is dropped by this rule too.

Try it: fragment merge

merge_fragmented_instances: when views barely overlap, one object can be fused into two. The smaller merges into the larger only if all three hold.

Points, not boxes: a desk's box contains everything standing on it. With a box test and cosine 0.55, a real capture merged a laptop, bottle, backpack, monitor, wallet and box into one "mac".

In the code: end of video: object_fusion/instance_fusion.py (finish, _rematch) and DoVSG's get_instances passes (DBSCAN, merge_objects, indexes_align_objects) · clean-up: object_fusion/postprocess.py (drop_structural_instances, merge_fragmented_instances, find_support_surfaces) · called from scripts/run_static_scene_graph.py build_graph_from_objects. Optional (tested, off by default): track rejection at commit (object_fusion.track_validation: thing/stuff probe, thin-plane test).
